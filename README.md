# React project (Vite)

Готовая заготовка React + Vite для Windows.

## Требования

- Node.js LTS
- npm (устанавливается вместе с Node.js)

Проверить установку в PowerShell:

```powershell
node -v
npm -v
```

## Запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).
Остановить сервер: `Ctrl+C`.

## Сборка

```powershell
npm run build
```

В исходной папке `src` находятся файлы React-приложения. Для разработки используйте `npm run dev`.
